# API project properties

## Purpose

Conventional .NET project directory for metadata and launch profiles.

## Responsibilities

Contains development project properties when they are intentionally versioned.

## What belongs here

- Versioned launch settings.
- Project metadata required by local tooling.

## What does not belong here

- Secrets.
- Production configuration.
- Application startup code.

## Related documentation

- [Local development](../../../../docs/runbooks/local-development.md).

## Current status

The directory is reserved for future versioned API launch settings.
