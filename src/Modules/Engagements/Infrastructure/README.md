# Engagements — Infrastructure

## Purpose

Contains the database mappings, provider adapters and technical implementations for the Engagements module.

## Responsibilities

Implements only concerns owned by Engagements and keeps dependencies flowing inward toward the domain.

## What belongs here

- database mappings, provider adapters and technical implementations.
- Supporting types and tests specific to this layer.
- Explicit dependencies required by the module.

## What does not belong here

- Concerns owned by another module.
- Host startup, HTTP pipeline or frontend code.
- Secrets or environment-specific values.
