# Architecture design

## Purpose

Canonical backend architecture and contract documentation.

## Responsibilities

Defines process topology, module boundaries, data ownership, security, API conventions, persistence and integration rules.

## What belongs here

- System architecture.
- Module ownership and dependency rules.
- API and event design.
- Persistence and observability conventions.

## What does not belong here

- Endpoint implementation.
- Local secrets.
- Temporary design discussions without a recorded decision.
