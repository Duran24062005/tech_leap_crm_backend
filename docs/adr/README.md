# Architecture Decision Records

## Purpose

Records decisions with lasting architectural or operational impact.

## Responsibilities

Captures context, the chosen decision, consequences and constraints.

## What belongs here

- Repository topology decisions.
- Authentication and infrastructure decisions.
- Changes to boundaries, contracts or deployment.

## What does not belong here

- Temporary task notes.
- Detailed feature requirements.
- Secrets or environment values.
