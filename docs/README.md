# Backend documentation

## Purpose

Documentation hub for the backend repository.

## Responsibilities

Organizes architectural decisions, API contracts, product design references and operational guidance.

## What belongs here

- Architecture and design documents.
- ADRs.
- API contracts.
- Runbooks.
- Implementation notes.

## What does not belong here

- Secrets.
- Generated OpenAPI artifacts.
- Temporary notes without an owner.
